# Prompt for Codex

Read all documents in docs/ before coding.

Implement one task at a time.

Do not introduce dependencies.

Keep dashboard independent from business commands.

Use Bash first.

Use Bash source config with indexed panel arrays.

Implement configurable panel count and layout.

Use one global synchronous refresh loop.

Do not implement remote SSH, alerts, history, per-panel refresh, timeout policy, or parallel command execution in V1.

Preserve terminal state on `q` and Ctrl+C.

Run the manual test plan before calling V1 complete.
